
# Car Sales Performance Analysis Dashboard

## Project Overview
An Excel-based data analytics project that analyzes car sales data from 2022 to 2023. The objective is to identify sales trends, compare company and regional performance, and understand customer vehicle preferences.

## Tools Used
- Microsoft Excel
- Data Cleaning and Validation
- Excel Formulas
- Pivot Tables and Pivot Charts
- KPI Analysis
- Interactive Slicers
- Data Visualization

## Dataset
- 23,906 car sales records
- Time period: 2022–2023
- Includes company, dealer, region, vehicle body style, transmission, price, and date fields.

## Key Performance Indicators
- Total Cars Sold: 23,906
- Total Sales: $671,525,465
- Average Car Price: $28,090.25
- 2023 Sales Growth: Approximately 23.7% compared with 2022

## Key Insights
- Total sales increased from approximately $300.34 million in 2022 to $371.19 million in 2023.
- Chevrolet recorded the highest total sales among the five companies analyzed.
- Austin was the highest-sales region in the regional analysis.
- SUVs were the most popular body style by sales volume.
- Automatic vehicles recorded higher sales volume than manual vehicles.

## Dashboard Features
- KPI cards for sales performance
- Monthly sales trend analysis
- Top company sales comparison
- Regional sales analysis
- Body style analysis
- Interactive slicers for Year, Company, and Region

## How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use the slicers to explore sales performance by year, company, and region.

## Learning Outcomes
This project provided practical experience in data validation, Pivot Table analysis, KPI creation, dashboard development, and translating data into business insights.
